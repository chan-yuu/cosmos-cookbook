# 如何贡献

Cosmos Cookbook 旨在创建一个专门空间，让 Cosmos 团队和社区能够开放地分享并贡献实用知识。我们非常欢迎你的补丁和贡献，一起构建这一宝贵资源。

## 为文档做贡献

这是一个渲染后的文档站点。若要为 Cosmos Cookbook 做贡献，请访问源码仓库：

**源码仓库：** [https://github.com/nvidia-cosmos/cosmos-cookbook](https://github.com/nvidia-cosmos/cosmos-cookbook)

所有贡献都应通过源码仓库提交，包括：

- 文档改进
- 新示例和配方
- Bug 修复和更正
- 成功案例与实用知识

## 完整贡献指南

如需了解如何贡献的详细信息，包括：

- 分享你的成功案例和实用配方
- 关于完整案例、不完整想法和知识空白的指南
- 数据集许可要求
- 代码评审流程
- 为你的工作签名

请参阅源码仓库中的完整贡献指南：**[CONTRIBUTING.md](https://github.com/nvidia-cosmos/cosmos-cookbook/blob/main/CONTRIBUTING.md)**
