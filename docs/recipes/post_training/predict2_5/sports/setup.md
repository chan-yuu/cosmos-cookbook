# 设置指南

## 系统要求

* 配备 Ampere 架构（RTX 30 Series、A100）或更新架构的 NVIDIA GPUs
* 与 [CUDA 12.8.1](https://docs.nvidia.com/cuda/archive/12.8.1/cuda-toolkit-release-notes/index.html#cuda-toolkit-major-component-versions) 兼容的 NVIDIA driver >=570.124.06
* Linux x86-64
* glibc>=2.35（例如 Ubuntu >=22.04）
* Python 3.10
